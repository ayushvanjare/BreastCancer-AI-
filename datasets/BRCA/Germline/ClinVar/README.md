# ClinVar germline variant evidence

This folder holds variant-level public ClinVar interpretations for BRCA1 and BRCA2. It does not contain individual patient genotypes, carrier status, or clinical outcomes. Use it for research on variant annotations only, not as a patient-level hereditary-risk model or a clinical validation cohort.

- Compressed NCBI summary records: `raw/`
- Filtered BRCA variant table and query provenance: `derived/`
- Reproducible retrieval code: `download_clinvar_brca_subset.py`

See `../../../DATA_INVENTORY.md` for scope and limitations.
