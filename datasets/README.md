# BreastCare AI datasets

This folder contains research data files only. Keep source data, labels, derived tables, and provenance separate. Do not put credentials, application databases, model checkpoints, or software installers here.

See [DATA_INVENTORY.md](DATA_INVENTORY.md) for current contents, status, permitted use, and missing data. Each source folder should include its own provenance and license notes before any training run.

**Clinical status:** no dataset in this project currently establishes clinical validation. Public research cohorts and ClinVar annotations are research resources; they do not replace independent clinical validation or medical-device review.
