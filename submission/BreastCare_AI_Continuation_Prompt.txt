PROJECT DEFINITION
BreastCare AI is a local research-software project that brings breast-cancer-related data workflows into one application. A signed-in researcher selects a workflow, uploads an authorized research file, the application checks the file and request, runs the available software/model step, and presents a readable result with its limits. Saved analysis records belong to the signed-in local account and can be reviewed or removed. The project is not a clinical diagnostic product, does not replace a clinician or genetic counsellor, and has not been clinically validated.

The application is intended to demonstrate a complete software workflow across data review, document text extraction, medical-image metadata inspection, histopathology experiments, and genomic data readiness. Each module must clearly distinguish an implemented feature from a research experiment, a metadata-only check, a planned feature, or a validated clinical capability. Never call a module a prediction model unless compatible trained weights are actually integrated and the target, data, and evaluation support that claim.
